SOBY → USDT returns are not accepting orders
USDT → SOBY purchases are enabled. Request a quote first, then send only the exact USDT amount to the deposit address and Ethereum USDT contract shown in the issued quote, before its 10-minute expiry. The SOBY payout is sent to the receiving wallet in that quote; the SOBYA network fee is deducted from the SOBY payout. Never send funds without a valid issued quote. SOBY → USDT returns remain closed until the wallet has USDT inventory and ETH for Ethereum gas. Do not send SOBY for a refund yet.

The project uses GitHub Issues, GitHub Actions, and a versioned JSON ledger; it does not require a separate hosting provider. Price changes are tied to confirmed settled quantities: +100 BPS for SOBY sold and −25 BPS for SOBY returned, proportionally to the 1,000,000 SOBY reference inventory. No time-only price changes are applied. The two exchange directions have independent activation gates so an unfunded refund route cannot block initial SOBY purchases.

Network routes: Ethereum Mainnet for USDT deposits/refunds · SOBYA EVM for native SOBY payouts/returns.
