Offline License Issuer

Owner-only tool. Use this file offline on a trusted device. The private key is generated and used in this browser only; it is never uploaded. Save the private key file in at least two secure offline locations. Never commit it to GitHub or send it to anyone. This tool does not verify payment transactions — verify every payment independently before issuing a license.

1. Create signing keys

Generate one Ed25519 key pair. Keep the private key secret. The public key must be added to the public app before licenses can be verified there.

2. Issue a license after payment verification

Verification checks the live chain ID, transaction receipt, recipient, exact 100 SOBY native transfer and at least 3 block confirmations. It does not send funds. If RPC access is blocked by the browser, do not issue until the transaction is independently verified.

License format

The signed payload fixes the product, plan, price and chain ID. Before signing, this tool queries SOBYA Mainnet RPC and checks the chain ID, successful receipt, exact 100 SOBY native transfer, receiving address and at least 3 confirmations. It also records used hashes and license IDs in this browser as a convenience. Browser storage is not a shared or tamper-proof registry: maintain a separate offline issuance register and never reuse a transaction hash.
