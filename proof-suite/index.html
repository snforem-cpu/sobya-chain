What this record confirms

A successful SOBYA transaction records the file's SHA-256 fingerprint and the submitting wallet address at a specific block. If a selected file has the same fingerprint, its bytes match the recorded file fingerprint.

The wallet address is public, but this record does not independently identify the person controlling it, prove who created the document, verify its contents, or establish legal ownership.

What this proves — and what it does not

A matching fingerprint shows that the selected file has the same bytes as the file fingerprint recorded in this transaction. It does not prove who created the file, that its contents are true, or that the signer had legal ownership.

The fingerprint and wallet address are public on-chain. File names and file contents are not sent. Each proof costs a separate 1 SOBY service fee sent to the SOBYA Proof service wallet. Any network gas is separate and shown by your wallet.
