الإثبات صحيح: توجد معاملة ناجحة في عقد SOBYA الرسمي، دفعت الرسوم المطلوبة وأصدرت حدث التسجيل الصحيح.

الملف مطابق: بصمة الملف الذي اخترته تطابق البصمة المسجلة على الشبكة. أما إذا كان الإثبات صحيحاً والملف غير مطابق، فالمعاملة موجودة لكن الملف المختار مختلف.

التحقق لا يثبت صحة محتوى الوثيقة أو الملكية القانونية أو هوية الأطراف أو سداد الفاتورة. لا نرفع الملف أو اسمه إلى الخادم؛ تُرسل استعلامات قراءة فقط إلى RPC العام.

للمطورين والشركات

اربط التحقق بموقعك أو تطبيقك

أصبحت خدمة HTTP API منشورة على Cloudflare Workers، ويمكن لموقعك أو تطبيقك إرسال طلبات تحقق آلية بصيغة JSON دون ربط محفظة أو رفع الملفات.

عنوان API الأساسي:
https://sobya-verify-api.snforem.workers.dev

فحص حالة الخدمة:
GET /v1/health

مسارات التحقق:

  • POST /v1/verify/proof — التحقق من إثبات ملف.
  • POST /v1/verify/invoice — التحقق من إثبات فاتورة وبياناتها.

يرسل تطبيقك بصمة SHA-256 فقط، ولا يرسل الملف نفسه. لا تحتاج إلى مفتاح API أو توقيع محفظة في النسخة الحالية.
