About SOBYA

Your assets. Your keys. Your choice.

SOBYA is an independent blockchain network designed around direct wallet ownership, transparent rules and open participation. The source code is public, so developers and users can inspect how the system is built.

◇

Open infrastructure

A public blockchain project built with open-source components and a source repository that developers can inspect and contribute to.

↔

Two ecosystems in view

Built on Cosmos SDK and CometBFT, with an EVM-compatible environment and Ethereum-style access for supported transactions.

⌘

Applications first

We are actively working toward dedicated blockchain applications that make the network useful beyond transfers.

Open by design

Why we chose GitHub Pages.

Our choice to publish the official SOBYA website through GitHub Pages on the public github.io domain is intentional. We want our public presence to reflect the open way we build the project: source code, updates and development history are available for anyone to inspect.

⌘

Public by choice

We connect our official website to a public development repository, making it easier for the community to move from what we publish to the code and history behind it.

◎

Verifiable development

Public commits and visible deployment workflows help people follow changes and independently review the work rather than relying only on our claims.

◇

Trust through openness

We believe trust should be earned through openness, accountability and verifiable work—not through expensive hosting, prestigious domain names or appearances.

Open source and public development do not mean that private user data, wallet secrets or every operational system are public. Always verify transactions and network information independently.

No unnecessary barriers. No hidden development. Open technology. Public verification.

SOBYA — Open by Design. Built on Transparency.

The SOBYA difference

Infrastructure that puts users first.

A different approach to digital ownership—grounded in open software, verifiable rules and direct access.

⌑

Direct ownership

Your wallet is under your control. Hold and manage supported assets with your own keys instead of depending on a custodian to maintain an account balance for you.

⌘

Public rules

Core software and protocol logic are open to inspection. Transactions follow code and network rules that anyone can review—not discretionary promises from an intermediary.

◎

Borderless access

Connect from anywhere with a compatible wallet and internet access. Public network access does not require opening an account with a central platform.

↗

Open entry

No credit check or platform account approval is built into basic wallet access. You choose your wallet and decide when to connect.

♧

Community participation

SOBYA is developed in the open. Contributions and proposed improvements can be discussed and reviewed publicly through the project’s open-source process.

◇

Independent infrastructure

The network is designed to support independent validator and infrastructure operators. Multiple public endpoints give users alternative ways to connect when a provider is unavailable.

The role of SOBY

One native coin. A network of possibilities.

SOBY is designed to connect activity across the SOBYA network. Its role begins with core network operations, while the ecosystem continues to develop new applications and services.

Network fees

Stay safe

Security starts with verification.

SOBYA will never need your wallet seed phrase or private key to help you connect to the network or submit a purchase request.

Protect recovery phrases

Never share your seed phrase or private key with anyone, including people claiming to be project support.

Verify network details

Use the chain ID and RPC details published on this official website. Check addresses carefully before sending assets.

Beware of false promises

No one can guarantee SOBY market prices, profits, exchange listings or investment returns.

Independent security audit: an external review was completed for seven SOBYA DEX smart contracts at source commit 81c78793b362d905df9a183580fbc212f7131143: WSOBY, SobyaV2Factory, SobyaV2Pair, SobyaV2Router, SobyaV2Oracle, SobyaV2UsdOracle and SobyaMultiMarketUsdOracle. The audit applies to that exact source revision; users should compare deployed bytecode and later code changes against the audited scope.
