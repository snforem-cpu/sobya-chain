Designed for network utility

SOBY is the native asset used by the network. Its denomination is consistent across the chain's native accounting and EVM-facing configuration. The same official project mark identifies both the SOBYA network and its native coin.

The project's token design also includes a capped validator reserve and a defined fee-distribution model. Detailed implementation and allocation information is maintained in the public source repository.

The role of SOBY

One native coin. A network of possibilities.

SOBY is designed to connect activity across the SOBYA network. Its role begins with core network operations, while the ecosystem continues to develop new applications and services.

Network fees

Use SOBY to pay transaction fees for supported activity on the SOBYA network.

Native transfers

Send and receive the network’s native digital asset between compatible SOBYA accounts and wallets.

EVM-compatible access

Interact with supported EVM tools and applications using the network’s published JSON-RPC interface.

Additional applications and trading integrations depend on their actual development and deployment. A market price or exchange liquidity is not guaranteed by the network design.

Stay safe

Security starts with verification.

SOBYA will never need your wallet seed phrase or private key to help you connect to the network or submit a purchase request.

Protect recovery phrases

Never share your seed phrase or private key with anyone, including people claiming to be project support.

Verify network details

Use the chain ID and RPC details published on this official website. Check addresses carefully before sending assets.

Beware of false promises

No one can guarantee SOBY market prices, profits, exchange listings or investment returns.

Quick reference

SOBYA glossary.

Native coin

The base digital asset of a blockchain. SOBY is the native coin of SOBYA.

Validator

A network operator that participates in consensus and block signing.

RPC

An interface that lets wallets and applications communicate with a blockchain node.

Gas

A measure of computational work used to calculate transaction execution costs.

Smart contract

Code deployed on a blockchain that executes according to its programmed rules.

Explorer

A website for inspecting blocks, transactions, accounts and other public chain data.
