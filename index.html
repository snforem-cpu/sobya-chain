About SOBYA

A network with a practical purpose.

Our goal is to develop dependable blockchain infrastructure and turn it into useful products. SOBYA is more than a token: it is the foundation for applications, services and community-led participation.

◇

Open infrastructure

A public blockchain project built with open-source components and a source repository that developers can inspect and contribute to.

Two ecosystems in view

⌘

Applications first

We are actively working toward dedicated blockchain applications that make the network useful beyond transfers.

Network technology

Built for an expanding ecosystem.

SOBYA combines a Cosmos-based chain foundation with EVM access. Wallet and developer integrations continue to evolve; supported endpoints and live network details are published below.

⚙

Cosmos SDK

Modular blockchain application architecture for native accounts, transactions and on-chain modules.

◉

CometBFT consensus

Byzantine fault-tolerant consensus and validator-based block production.

Ξ

An EVM execution environment and JSON-RPC access for Ethereum-style wallets and transactions.

Designed for network utility

SOBY is the native asset used by the network. Its denomination is consistent across the chain's native accounting and EVM-facing configuration. The same official project mark identifies both the SOBYA network and its native coin.

The project's token design also includes a capped validator reserve and a defined fee-distribution model. Detailed implementation and allocation information is maintained in the public source repository.
