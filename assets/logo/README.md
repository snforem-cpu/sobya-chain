# SOBYA Logo Assets

The official SOBYA coin mark is the user-provided crystal-and-gold-orbit artwork.

## Files

- `sobya-coin-128.png`: optimized 128×128 RGBA PNG for wallet/token metadata and compact UI use.

The artwork is intentionally preserved with its dark navy background and original composition. The repository asset is a compact raster derivative; the original high-resolution upload remains the design master and should be used when generating larger website or explorer artwork.

## Usage guidance

- Keep the icon square and do not crop the gold orbital ring.
- Do not add text over the mark.
- Use the same artwork consistently across the project website, explorer, wallet metadata and token lists.
- A repository asset alone does not make wallets display the token icon. Each wallet or token registry has its own metadata, listing and review requirements.
